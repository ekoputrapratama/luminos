## 🚀 Overview

**Velra** is a Python framework for building desktop applications using web technologies. It blends the power of Python with the flexibility of HTML, CSS, and JavaScript — giving developers full control over logic, UI, and modular architecture.

Whether you're crafting a native-feeling tool or a hybrid interface, Velra empowers you to build fast, modern apps without sacrificing developer experience.

---

## 🧩 Features

- 🐍 **Python-first architecture** — write your logic in Python, not JavaScript
- 🌐 **Web-powered UI** — use HTML/CSS for layout and styling
- 🧱 **Modular design** — structure your app with reusable components
- ⚡ **Fast startup** — lightweight runtime with minimal overhead
- 🎯 **Cross-platform** — works on Windows, macOS, and Linux (in progress)

---

## 📦 Installation

```bash
pip install velra
```

## Dependencies

You will need the following components installed, including their development
headers and libraries:

- Python 3.9, or newer
- PyQt5
- QtWebEngine
- A working PyGObject installation.
